# Creative Direction

## Core concept

CALLBACK / King Prompter takes place inside a **chaotic medieval castle game show**.

The world should feel theatrical, handmade, comic and slightly out of control — like a royal competition run by an overconfident pigeon and a production crew barely keeping the castle functioning.

## Central characters and symbols

### Pigeon host

The pigeon is the recurring theatrical host/mascot. It should feel expressive, slightly self-important, funny and visually recognizable across menus, transitions, game rooms and reactions.

### Crown

The crown is the primary symbol of winning, status, conflict and escalation. It should recur in scoring, transitions, victory presentation and comic conflict.

## World structure

Different games can occupy different castle areas. A game mode's background should feel like a real part of the same castle universe rather than a completely separate theme.

Possible location logic can include throne room, great hall, dungeon, tower, courtyard, library, kitchen, armory or other approved spaces, but exact mode-to-room assignments remain open until documented.

## Established opening/menu language

Preserve the visual sequence already established in the startup/menu work:

1. typing / prompt creation
2. AI processing machine
3. royal pigeon mini-scene
4. crown fight
5. comic explosion
6. main-menu reveal
7. looping menu animation

The game should feel like a continuation of this sequence rather than a separate visual product after the menu.

## Palette

Core direction:

- navy
- cream
- crown yellow
- coral
- cyan
- purple

Use palette roles consistently rather than randomly applying every color to every screen.

## Materials / motifs

Prefer:

- painted stage flats
- banners and pennants
- parchment/paper elements
- theatrical lights
- wood/stone used playfully rather than photorealistically
- crown shapes
- speech/prompt cards
- comic impact shapes
- ropes, pulleys, ladders and improvised castle-show machinery
- visible production chaos

## Tone

Desired:

- absurd
- theatrical
- playful
- energetic
- clever
- approachable
- family/friend party-game energy

Avoid:

- grimdark medieval fantasy
- realistic violence
- generic RPG menus
- luxury fantasy aesthetics
- photorealistic castles as the default UI background
- generic neon/cyber AI imagery disconnected from the castle-show world
- visual clutter that obscures gameplay
