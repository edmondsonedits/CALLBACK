# Bowl of Fools

**Status:** APPROVED RULE DIRECTION; integration not verified  
**Name:** working title

A medieval/Renaissance Fishbowl-derived team game for local or Remote Live play. Players create anonymous scrolls, then both teams reuse the same bowl across three increasingly restrictive rounds.
